# Outlet Park Rzeszów – model 3D

Interaktywny model 3D koncepcji parku handlowego Outlet Park Rzeszów przy drodze S8, w skali 1:1.

## Funkcje

- obrót, przybliżanie i przesuwanie widoku, kliknięcie budynku pokazuje jego powierzchnię i kondygnacje
- suwak pory dnia oraz pory roku (lato, jesień, zima)
- ruch aut i pieszych, fontanna, flagi, ekran LED na pylonie
- wycieczka kamerą z podpisami
- spacer z wysokości pieszego (W A S D / strzałki, joystick na telefonie)
- rozbiór kondygnacji budynków dwupoziomowych

## Uruchomienie

Cały model to jeden plik `index.html`. Biblioteka three.js i czcionki ładują się z CDN, więc potrzebny jest internet.

Lokalnie: otwórz `index.html` w przeglądarce (Chrome, Edge, Safari, Firefox).

## GitHub Pages

1. Wrzuć `index.html` i `README.md` do repozytorium.
2. W repozytorium: **Settings → Pages → Build and deployment → Deploy from a branch**, gałąź `main`, folder `/ (root)`.
3. Po chwili model będzie dostępny pod adresem `https://<nazwa-uzytkownika>.github.io/<nazwa-repozytorium>/`.
